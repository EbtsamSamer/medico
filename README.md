🩺 Medico

Medico is a modern healthcare mobile application built with Flutter to help users discover doctors and manage their healthcare profile through a simple and user-friendly experience.

The project focuses on implementing a clean and scalable Flutter architecture, with an emphasis on API integration, state management, authentication, and separation of responsibilities
